codesys-to-astra → REGUL

PLCopen XML проекта CODESYS 3.5 (ОВЕН ПЛК2xx и другие) → файл импорта Astra.IDE 1.7.2.2, отчёт с исходами по правилам, замены библиотек ОВЕН, карта каналов Mx210 → Modbus REGUL, приоритеты задач. Тот же Python-код, что в CLI, работает здесь через Pyodide.

Перетащите сюда PLCopen XML или выберите файл: — файл не покидает браузер.
