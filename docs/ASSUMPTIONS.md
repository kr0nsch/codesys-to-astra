# Допущения

Что принято без проверки на контроллере или без публичного источника. У каждого допущения — где оно
живёт в коде и как его снять. Пока допущение не снято, правило ставит исход `check` (сверить), а не `auto`.

| № | Допущение | Где | Как снять |
|---|---|---|---|
| A1 | Котельная `boiler-plc210` вымышлена; слой ОВЕН (дерево ПЛК210, OwenRTC, Watchdog, МВ210-101, МУ210-402 под Modbus TCP Master) наложен скриптом `tools/corpus/owen_overlay.py`, потому что проба P7 (таргеты ОВЕН в CODESYS 3.5.17.30) не выполнялась. `DeviceIdentification` узлов ОВЕН — заглушки `SYN …` | `corpus/boiler-plc210/`, `FIXTURE.toml` (класс `synthetic`) | настоящий экспорт проекта ПЛК210 с флагом «объявления как простой текст» |
| A2 | Имена каналов узлов ОВЕН и шаблонов Mx210 («Вход 1/Измеренное значение», «Date And Time», «Last Exception Code») взяты из документации ОВЕН, а не из devdesc | `cds2astra/data/owen_modules.toml` (страница у каждой строки) | экспорт проекта с устройствами ОВЕН (P7) |
| A3 | Сигнатуры POU ОВЕН — только те, что есть в PDF (страница и SHA-256 документа в `data/owen_signatures.toml`). POU без страницы не заменяется, остаётся `todo` | `data/owen_signatures.toml`, `data/libmap/*.toml` | — (правило: нет источника — нет строки) |
| A4 | Поведение функций AstraCompat повторяет описание в документации ОВЕН. Двойники, AstraCompat и тесты написаны по одной документации, поэтому совпадение тестов не доказывает совпадения с ПЛК210 | `src/`, `tests/` | сверка на ПЛК210 (`HARDWARE_VALIDATION.md`, раздел 3) |
| A5 | Порядок слов FLOAT32 модулей Mx210 через драйвер `PsIoDrvModbusTcpMaster_OS` неизвестен; в `GVL_IO` стоит `eC2aWordOrder := HighWordFirst`, поменять можно одной строкой | профиль `modbus.word_order_float32 = unknown`, правило C2A-IO003 | E8 или ПЛК (`HARDWARE_VALIDATION.md`, раздел 2) |
| A6 | `SIZEOF(POINTER)` на REGUL R500 неизвестен: по devdesc не определить | профиль `platform.pointer_size = unknown`, правило C2A-PTR001 | проба E8 (`OWNER_EXPERIMENTS.md`) |

Без уточнения образец niksosov (родной проект Astra.IDE) получал бы ложные правки | `cds2astra/tasks.py`, 13 золотых случаев в `test_data.py` | — (решение проекта) |
| A8 | Каналы Modbus: соседние регистры с пропуском до 4 объединяются в один канал, канал — не больше 120 регистров. 125 — предел протокола для FC 3/4, 120 взято с запасом. Адрес вне карты регистров по протоколу даёт исключение 02 (Illegal Data Address), поэтому длинный пропуск делит блок, а короткий (до 4) объединяется в расчёте, что такие регистры у модуля есть | `rules/project_rules.py` (`MAX_GAP`, `_split_blocks`) | карта регистров конкретного модуля |
| A9 | `WORD_TO_HEX_STR` ОВЕН дополняет результат нулями до 4 символов. В документации пример с четырьмя символами, явного правила нет | `src/POUs/F_C2aWordToHexStr` | вызов на ПЛК210 с `16#00AB` |
| A10 | IL не импортируется ни в одну из IDE (P4), включить IL скриптом нельзя (у ScriptEngine нет API опций). | A11 | Модель трудоёмкости: треугольные оценки минут на находку по правилам, калибровка по переносу kns-port-domestic (`docs/port_metrics.json`: одна итерация сборки снимает маркеры проверки пачкой, правка Modbus — 1 ч).
